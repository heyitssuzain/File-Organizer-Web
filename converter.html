Honest limits

  • GIF becomes a still image (first frame).
  • Large images can hit browser canvas memory limits; downscale if needed.
  • Text is read as UTF-8 or UTF-16. Legacy encodings may need re-saving.
  • HTML → PDF extracts readable text; it does not reproduce CSS layout or images.
  • Text PDFs use a bundled Latin/Greek/Cyrillic font. CJK and emoji are rejected with the missing characters instead of being silently blanked.
  • XLSX export is one-way; this tool does not open spreadsheets.
  • Keep the tab open while converting.
Practical guide

Pick the right output the first time

The converter deliberately supports a focused set of formats. That keeps every conversion predictable and fully local. Here is what each group is good for, plus the limits that matter before you convert a batch.

Supported conversions

InputOutputsBest for
PNG, JPG/JPEG, WebP, BMP, GIF, SVG, AVIF, ICOPNG, JPG/JPEG, WebP, BMPPreparing photos for the web, flattening transparency onto a colour, converting screenshots or scanned images

CSV, TSV, JSONCSV, JSON, XLSXOpening a JSON export in Excel, normalising delimiters, producing a spreadsheet from a data dump

PDF is an input only for the PDF Merger; this converter does not turn PDFs into Word documents or images. Audio and video conversion is not offered because no dependable local engine is bundled.

Three useful examples

  • Shrink a set of phone photos: choose JPG output, set the maximum dimension to 1600 px, and leave quality at 92%. The originals stay untouched; download the resized copies individually or as a ZIP.
  • Turn meeting notes into a PDF: add a Markdown file, choose PDF, then set A4 and 18 mm margins. The PDF uses a bundled font and rejects characters the font cannot draw instead of producing blank boxes.
  • Open a JSON export in a spreadsheet: choose XLSX. Values are written as inline strings, so a cell beginning with = stays text and is never executed as a formula.

What will not survive

  • GIF animation: only the first frame is converted.
  • HTML layout: HTML → PDF extracts readable text, not CSS columns, colours or embedded images.
  • CJK and emoji in text → PDF: the bundled Noto Sans font does not include them, so conversion fails with the exact missing characters.
  • Spreadsheet formulas, styles or multiple sheets: XLSX output is a single, plain data sheet and is never read back.
  • Original EXIF metadata: images are re-encoded through Canvas; orientation is applied, but other metadata is not preserved.

Frequently asked questions

Are my files uploaded during conversion?

No. The browser reads the bytes you selected, converts them in memory, and creates a local download. The page loads only its own assets. See the privacy policy for the hosting details that apply to any website.

Is converting an image lossless?

PNG output is lossless, and a same-format image conversion with no resize is passed through byte-for-byte. JPG and WebP are re-encoded at the quality you choose; BMP is uncompressed, so files are usually larger. Converting JPEG → PNG cannot restore detail that JPEG already discarded.

Can I convert several files at once?

Yes, up to 50 files per batch, 150 MB per file and 300 MB total. Each file keeps its own output choice. Use Download all as ZIP when more than one result is ready.

Why is an unsupported file rejected instead of converted?

The converter only offers outputs it can actually produce locally. A file is rejected when its format is not in the supported list, when the browser cannot decode it, or when it exceeds the size limit. Nothing is silently skipped or replaced with a placeholder.

Does it run in the background?

No. Conversion happens while the tab is open and progresses one file at a time to keep memory predictable. Closing or reloading the page discards the queue and all un-downloaded results.

Troubleshooting

Message or symptomFix
“This format is not supported by the local converter”The extension or MIME type is outside the supported list. Convert it with a desktop tool first, or use a supported input.
“This browser cannot decode that image format”The file is corrupt, mislabelled, or uses a codec your browser lacks. Try opening it in an image viewer, then re-save it as PNG or JPG.
PDF text conversion rejects charactersThe bundled font lacks those glyphs (often CJK or emoji). Export as HTML or TXT instead, or remove/replace the characters.
A large batch stops or the tab slowsBrowser memory is finite. Split the batch, lower the image resolution, and close other memory-heavy tabs. No partial file is uploaded anywhere.
The downloaded file will not openConfirm the output extension matches the chosen format, and try opening it in a different application. If it still fails, keep the original and report the browser, input format and exact error on the contact page.

Privacy

What actually happens to your files

This page describes the real implementation, not aspirations. Each claim below maps to a specific technical fact about this site.

Last updated: October 21, 2026

1. Files are never uploaded

AuraFlow Web has no backend that could receive files. The organizing and conversion logic is JavaScript that ships with the page and runs inside your browser tab. Categorization, previews, duplicate hashing, image conversion, PDF creation and PDF merging all happen on your machine. There is no network request carrying file data — you can verify this in your browser's dev tools (Network tab) while using any tool.

2. Access is requested only when you act

The app asks for nothing until you click Select folder, Select files, use a tool's file picker, or drop files onto a panel. When you organize into a real folder (Chromium browsers), your browser shows its own permission prompt and asks for read & write access to the exact folder you pick. AuraFlow only writes inside that folder, and only to category folders it creates for your confirmed plan. Converters and PDF tools read only the files you choose and return a download; they never write to your folders.

3. No analytics, telemetry or tracking cookies

Today this site has no first-party analytics, no advertising scripts, no session-replay or fingerprinting code, and no tracking cookies. The only network requests are for the page itself and its own assets (JavaScript, CSS, favicon, the Open Graph image, and the bundled PDF font when you create a text PDF). Those requests go to this site's host, Vercel; they do not contain your selected files, filenames, folder paths or conversion results.

Your preference for light or dark theme is stored in your browser's localStorage — on your device, and never transmitted by AuraFlow. If advertising is enabled later, section 9 explains exactly what changes and which choices you will have. AuraFlow will not add silent tracking.

4. What is (and isn't) stored

Stored locally, only in your own browser:

  • Your light/dark theme choice (one localStorage key, auraflow-theme)
  • Files and PDFs you download (they go to your Downloads folder — you control them)

Not stored anywhere: selected file lists, conversion queues, image previews, page counts, merged documents, duplicate hash results, executed run manifests or conversion history. These live only in the tab's memory. Preview images use temporary blob: URLs that are revoked when you remove an item or leave the page. Close the tab and the in-memory copies are released.

AuraFlow does not write file contents, filenames or metadata to localStorage, sessionStorage, IndexedDB or cookies. There is no service worker, no offline file cache, and no server-side database of your activity. AuraFlow itself sets no cookies. The hosting provider may process request metadata as described in section 8.

5. Local conversion and PDF engines

Images are decoded and re-encoded by the browser's own Canvas engine. Text PDFs and PDF merging use pdf-lib; text PDFs also use fontkit with a bundled Noto Sans font served from this site. XLSX files are written as a minimal local OOXML/ZIP package without a spreadsheet service. None of these libraries receives a network request containing your file data.

Large PDF jobs run in a dedicated Web Worker. The worker receives only the bytes needed for that job, returns the result to the tab, and is terminated when you leave the page. It has no storage access and makes no network requests. PDFs are treated strictly as data: they are parsed, never executed.

HTML output is sanitized: remote resources are not embedded, links are restricted to safe schemes, and the generated page is marked noindex. AuraFlow does not fetch images, stylesheets or scripts referenced by the files you convert.

6. Duplicate detection only reads file contents

To find true duplicates, the app reads the bytes of same-size files and computes SHA-256 hashes — inside a Web Worker, in your browser, in streamed chunks. The hash is a fingerprint for comparison only; it is never sent anywhere and never written anywhere.

7. Security boundaries you should know about

Files you select are treated as data — never executed. Filenames shown in plans, queues and manifests are HTML-escaped, and store only what you picked. The organized ZIP is built locally with a checksummed archive writer. No AI models, no external services, no "anonymous processing" — because there is nobody to process for.

8. Hosted pages (this website itself)

The site is served as static files by Vercel. Like any web host, Vercel processes standard request metadata (such as IP address, date and time, requested URL, user agent and basic device/network information) to deliver the site, keep it available and protect it from abuse. Vercel may retain that metadata according to its own policies; AuraFlow does not receive your file contents or a per-visitor file history, and does not add its own server-side logging.

Files are processed in the tab, so file names, contents and conversion results never appear in a URL, query string or request body. Vercel operates infrastructure in multiple regions; request metadata may be processed outside your country. See Vercel's privacy documentation for its retention periods, subprocessors and transfer safeguards.

Hosting privacy: Vercel Privacy Policy.

9. Advertising and cookies (when enabled)

AuraFlow may display advertising to support the free service. Advertising is not enabled on the current site. If Google AdSense or another advertising partner is enabled in the future, this policy and the site's consent flow will be updated before any ad script loads.

When advertising is enabled, third-party vendors — including Google — may use cookies or similar technologies to serve ads based on a user's prior visits to this website or other websites. Google's use of advertising cookies enables it and its partners to serve ads to users based on their visit to this site and/or other sites on the Internet. These cookies do not give advertisers access to the files you process here, and AuraFlow will never send your selected files, filenames, hashes or folder contents to an ad network.

You will be able to opt out of personalized advertising by visiting Google Ad Settings, and learn how Google uses data from partner sites at How Google uses data. You can also visit aboutads.info to opt out of some third-party vendors' use of cookies for personalized advertising.

Where required — including the EEA, the UK and Switzerland — advertising will use a consent management platform and will not serve personalized ads, or set non-essential advertising cookies, without your consent. You will be able to change or withdraw that choice at any time. For visitors in California and other regions with similar laws, AuraFlow does not sell personal information and does not share file data with advertisers.

If ads are not enabled, this section describes what would apply when they are. The current site loads no advertising scripts and sets no advertising cookies.

10. Your privacy rights

Depending on where you live, you may have the right to request access to, correction of, or deletion of personal information, to object to or restrict certain processing, or to lodge a complaint with a data protection authority. AuraFlow does not maintain user accounts or a database of your files, so in most cases there is no stored file record to access or delete.

For questions or requests about this site, email thisissaddu3@gmail.com with “Privacy request” in the subject. Requests about hosting logs may need to be directed to Vercel, because AuraFlow does not control those logs. We will respond on a best-effort basis and within any period required by applicable law.

11. Children's privacy

AuraFlow is a general-purpose file utility, not a service directed to children. It has no accounts, profiles, chat or user-generated public content, and it does not knowingly collect personal information from children. If you believe a child has sent personal information by email, contact the address above and it will be deleted.

12. Changes to this policy

This policy may be updated when the site's features, hosting or advertising arrangements change. The “Last updated” date at the top of the page shows the current version. Material changes — especially the introduction of advertising, analytics or a new third-party service — will be reflected here before the change takes effect.

13. Who runs AuraFlow

AuraFlow is an independent, open-source project maintained by Suzain. It is not a company, and it has no separate data-protection officer. Privacy questions, security reports and legal notices can be sent to thisissaddu3@gmail.com or through the contact page.

Your file contents stay on your device. The host sees normal web requests, not your documents — and no advertising or analytics is active today.

How it works

Organize a folder without gambling with your files

Most file organizers ask you to trust a progress bar. This one shows you the complete plan first, keeps every original until the copy is verified, and never overwrites an existing name. Everything below describes the actual browser behaviour.

Step by step

  1. Choose a source. Select a folder in Chrome or Edge for direct sorting, select individual files, or drag files/folders onto the drop panel. Nothing is read until you do this.
  2. Review the plan. Every file gets a category and a destination. Use By type, By extension or By date; the totals and conflict badges update immediately.
  3. Check the edge cases. Temporary and system files are skipped by default. Unknown extensions go to Others — they are never discarded. Name collisions get _1, _2 and so on.
  4. Choose Move or Copy. Move writes a full copy, verifies its size, then removes the original. Copy leaves every original in place. If your browser cannot remove the source, the app reports a copy instead of pretending it moved.
  5. Confirm, then keep the manifest. A run summary lists every destination and any error. Download the JSON, CSV or TXT manifest for an audit trail; use Undo this run while the tab remains open.

Supported files and real limits

  • 11 categories: Documents, Images, Videos, Audio, Archives, Code, Executables, Design & 3D, Fonts, Data, Others.
  • Extensions are case-insensitive. Detection uses the filename extension, not the file's contents.
  • Folder reads stop at 3 levels deep and 5,000 files per selection.
  • Organized ZIP downloads are stored (uncompressed) and capped at 2 GB of selected files.
  • Duplicate detection hashes files up to 512 MB; larger files still organize normally.
  • Direct folder writing needs the File System Access API (Chromium desktop browsers). Firefox, Safari and mobile browsers get the ZIP instead.

A realistic example

A Downloads folder contains 240 files: installers, PDF invoices, screenshots, a few ZIPs and two copies of the same presentation. Choose By type and the plan proposes:

  • Documents/ for the invoices and presentation
  • Images/ for screenshots and photos
  • Executables/ for installers
  • Archives/ for ZIPs

The duplicate presentation is flagged only when its content hashes match. If both files are kept, the second is renamed rather than overwriting the first.

Frequently asked questions

Does the organizer upload my files?

No. The categorization, duplicate hashing, previews and ZIP creation run in this tab. The only network requests are for the page and its own assets; your filenames and file bytes are not sent to a server.

Why does Chrome refuse to open my Downloads or Documents folder?

Chromium protects certain system locations and returns “Cannot open this folder because it contains system files.” Use Select files and press Ctrl+A in the picker, choose a subfolder, or drag the files in. This is a browser rule, not an AuraFlow limitation.

What is the difference between Move and Copy?

Move is a verified copy followed by removal of the original. Copy writes the destination and leaves the original untouched. If removal is unavailable or the source changed after the scan, the result is labelled as a copy — never as a move.

Will an existing file be overwritten?

No. The plan checks names in the plan and, for folder sorting, the files already in each destination folder. A collision becomes name_1.ext instead. The destination name is checked again immediately before writing.

Can I undo a run?

Yes for true moves made through a picked folder, while the same tab stays open. Moves of individually selected files cannot be undone because the browser never exposes their parent folder. Copied files are intentionally not removed by undo.

Does it work offline?

Once the page and its assets have loaded, the current tab can keep processing without a network connection. There is no service worker, so opening the site again from scratch still needs a connection.

Troubleshooting

What you seeWhat to do
Nothing appears after selectingThe file type may be excluded, or the folder's contents are deeper than 3 levels. Check the skip notes in the plan.
A move fails with “permission denied”The file may be open in another program or the folder lost write access. Close the other app and run again; files already processed are not affected.
Results say “copied — original kept”The browser could not remove the source, or the source changed after the scan. Use the manifest to clean up manually, or retry from a folder selection.
ZIP exceeds the 2 GB limitOrganize in smaller batches, or use Chrome/Edge for direct folder sorting and undo.
The page feels slow on a huge folderSelections are capped at 5,000 files for a reason. Split the job and close other heavy tabs to free memory.

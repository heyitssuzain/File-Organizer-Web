Practical guide

Combine PDFs without flattening them into pictures

Merging is usually the last step before sending a document to someone. This tool copies pages from each source, in the order shown in the queue, and writes one new PDF locally. Text stays text, vectors stay sharp, and page sizes are preserved.

Good uses

  • Combine a cover letter, CV and references into one application PDF.
  • Join monthly invoices or receipts into a single archive for an accountant.
  • Assemble a contract from separately reviewed sections while keeping signatures intact.
  • Put scanned forms and digitally generated pages into one document without recompressing either.

Frequently asked questions

Are my PDFs uploaded for merging?

No. Files are read in the tab, copied in a local Web Worker with pdf-lib, and returned as a download. The site has no merge endpoint and no document storage. See the privacy policy for hosting-level request metadata.

Does merging reduce quality?

Pages are copied rather than rasterized, so text, images and vectors are not re-rendered as a screenshot. The output may still be larger than the sum of the inputs because shared resources can be duplicated by the PDF library.

Can I merge selected pages instead of whole files?

Not in this version. The queue works at file level: every page of every added PDF is included. To omit pages, create trimmed copies in a PDF editor first, then add those files.

Why is my encrypted PDF rejected?

The local library cannot open password-protected files safely without a password prompt. AuraFlow does not ask for or transmit passwords. Unlock the document in your PDF reader, export an unprotected copy, and add that copy instead.

What is the batch limit?

Up to 40 PDFs or 300 MB per batch. Page counts are read locally before merging so you can spot an unexpectedly large or empty file first.

Does the merged PDF keep metadata?

The output is created fresh with neutral AuraFlow metadata (title, creator and dates). Source document metadata, bookmarks and forms should not be relied on. The visible page content is what is preserved.

Troubleshooting

ProblemWhat to try
“This file could not be read as a PDF”The file may be damaged or use an unsupported feature. Open it in a PDF reader and re-export/save a clean copy, then add it again.
Pages are in the wrong orderDrag the file rows or use the arrow buttons. The queue order, top to bottom, is the final page order.
The merge button stays disabledRemove invalid or encrypted files. The queue blocks merging while any entry cannot be read.
The download is unexpectedly largeMerge fewer files at once, or compress the source PDFs in a PDF editor first. The merger does not recompress page content.
The tab slows or crashesLarge jobs consume real memory. Split the merge into two documents and combine those afterwards if necessary.
